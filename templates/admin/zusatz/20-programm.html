Wochenprogramm

Welches Layout eine Zone wann spielt: morgens das Tagesprogramm, mittags die Speisekarte, abends der Film. Im Kalender ziehen, um einen Eintrag anzulegen; auf einen Block tippen, um ihn zu bearbeiten. Ohne Eintrag spielt die Zone ihr Layout aus der Zonen-Übersicht. Ein Ausnahmetag (Feiertag) gewinnt vor allem anderen.

Eintrag

Ein Ende vor dem Beginn läuft über Mitternacht (20:00 bis 02:00). Ende 00:00 bedeutet Tagesende.

Ausnahmetage

Sofortmeldung

Eine Meldung über allem, auf jedem Schirm dieser Station, sofort: Räumung, Hinweis, Pause. Sie bleibt, bis sie beendet wird oder die Dauer abläuft — auch wenn eine Anzeige neu lädt. Per Webhook geht das auch von außen (siehe Auslöser).
